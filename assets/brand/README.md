# Brand asset sources

The README header uses repository-hosted copies so that the logos remain stable
across GitHub, PyPI, and Hugging Face. Each mark is either already opaque or is
placed on an opaque white clear-space panel for legibility in both light and
dark themes; its artwork, colors, and proportions are unchanged.

| KAI² Lab logo | [KAI² Lab](https://kai2.umbc.edu/) |
